# Student Task Manager

A beginner-friendly full-stack starter project for managing student assignments and tasks.

## Technology stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: SQLite (planned for the next development step)
- API format: JSON REST API

## Features planned
- View all tasks
- Create a task
- Update task status
- Delete a task
- Filter tasks by status

## Run the backend
1. Install Node.js (LTS).
2. Open a terminal in `backend`.
3. Run `npm install`.
4. Run `npm run dev`.
5. API health check: http://localhost:5000/api/health

## Run the frontend
1. Open another terminal in `frontend`.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Current starter status
This repository contains a working Express health endpoint and a simple React screen. Task CRUD routes and database integration are defined in `ARCHITECTURE.md` as the next implementation steps.
